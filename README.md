# FAERS Disproportionality Analysis

The FDA Adverse Events Reporting System Disproportionality analysis tests several methods of disproportionality analysis for the FAERS database, such as improved duplicate detection and cleaning methods or detection of ADR signals across multiple years.

# Files

Data can be downloaded from the [FDA website](https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html) for years 2020-2024, Q1-Q4. 

## Instructions
Extract the FAERS files to the documents folder, run R file *functions research faersquarterly.R* to initialize the functions needed to run the code, and run *faers disproportionality analysis.Rmd*.
